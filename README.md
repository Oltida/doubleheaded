# DOUBLEHEADED. 🦅
DOUBLEHEADED is an Albanian-inspired streetwear website built with React. It features a collection of T-shirts, sweatpants, matching sets, caps, and accessories inspired by the Albanian double-headed eagle.

## Built With
- React + Vite
- JavaScript (JSX)
- HTML & CSS

## How to Run Locally
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost link in your browser.
